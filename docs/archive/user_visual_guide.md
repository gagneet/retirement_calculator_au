## Screenshot Capture Guidelines

### For Contributors Adding Screenshots:

1. **Resolution**: Capture at 1920x1080 for desktop, 375x667 for mobile
2. **Format**: PNG for clarity, compress for web if needed
3. **Naming**: Follow the convention `##-descriptive-name.png`
4. **Content**: Show realistic Australian financial data
5. **Privacy**: Use demo data, never real personal information
6. **Annotations**: Add callouts for key features where helpful
7. **Consistency**: Use the same browser (Chrome recommended) for all desktop shots

### Recommended Tools:
- **macOS**: Command+Shift+4 for selective screenshots
- **Windows**: Snipping Tool or Snip & Sketch
- **Linux**: GNOME Screenshot or KSnapshot
- **Browser Extensions**: Awesome Screenshot, Lightshot
- **Professional Tools**: Snagit, CloudApp
